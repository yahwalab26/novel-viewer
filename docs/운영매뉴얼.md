# 운영 매뉴얼 (편집자용)

개발 지식 없이 할 수 있는 일상 업무 정리입니다. 화면 이름은 Supabase 업데이트로 조금 달라질 수 있습니다.

## 1. 새 작가 추가하기
1. **Supabase** → 프로젝트 → **Authentication → Users → Add user → Create new user**
   - 이메일과 임시 비밀번호 입력, **Auto Confirm User** 체크 → 만들기
2. **뷰어**에 편집자로 로그인 → **서버 원고** → 원고 카드의 **작가·공유** → 아래쪽 **작가 추가**에 그 이메일 입력 → 추가
3. 같은 창에서 작가 이름 옆 **배정**을 눌러 원고를 배정 (공유 스위치가 켜져 있어야 작가에게 보임)
4. 작가에게 주소와 임시 비밀번호를 전달하고, 로그인 후 상단 **비밀번호**에서 바꾸도록 안내

## 2. 원고 올리기 · 수정본 · 삭제
- **올리기**: 서버 원고 탭 → **+ 원고 올리기** (EPUB·DOCX·HWPX·HWP, 여러 개 가능). 같은 파일은 중복 등록되지 않습니다.
- **수정본(개정)**: 원고 카드 **개정본** → 새 파일 선택. 작가에게는 최신본이 보이고, 작가의 형광펜은 같은 문장을 찾아 위치를 다시 맞춥니다. 문장이 많이 바뀌면 일부 형광펜이 목록에서만 보일 수 있습니다.
- **삭제**: 카드 **삭제** → 작가들의 형광펜·메모·북마크도 **함께 지워지고 되돌릴 수 없습니다.** 삭제 전에 필요하면 메모를 백업하세요(5번).

## 3. 공유 켜기/끄기
- 작가·공유 창에서 작가별 **공유** 스위치. 끄면 작가는 **즉시** 원고와 자기 메모가 보이지 않습니다(데이터는 보존, 다시 켜면 복구).
- **복사 허용**: 꺼 두면 작가 화면에서 복사·인쇄가 막힙니다. 단, 화면 캡처 등은 막을 수 없으니 **유출되면 안 되는 원고는 공유 자체를 하지 않는 것이 유일한 보장**입니다.

## 4. 작가의 형광펜·메모 보기
원고를 열면 작가들의 형광펜이 **점선 윤곽**으로 함께 보입니다. 탭하면 작성자와 메모가 나오고(읽기 전용), 상단 **메모** → **보기**에서 작가별로 걸러볼 수 있습니다.

## 5. 백업 (정기적으로)
무료 Supabase 플랜은 자동 백업이 없거나 제한적일 수 있습니다(대시보드 **Database → Backups**에서 확인). 최소한 아래를 **월 1회** 하세요.
1. **원고 원본**: 편집자 PC의 원본 파일을 따로 보관 (서버에도 원본이 있지만 이중 보관)
2. **메모·배정 데이터**: Supabase **Table Editor** → 스키마를 `viewer`로 선택 → `annotations`, `assignments`, `bookmarks` 표를 각각 **Export → CSV**로 내려받아 보관
3. 복구가 필요하면 개발 담당에게 CSV와 함께 요청

## 6. 계정 문제
- **비밀번호 변경**(본인): 로그인 후 상단 **비밀번호**
- **비밀번호를 잊었을 때**: 로그인 전 재설정 화면은 아직 없습니다. Supabase **Authentication → Users**에서 해당 사용자의 메뉴(…)로 비밀번호 재설정/변경을 하세요. 화면에 없으면 개발 담당에게 문의하세요.
  - ⚠ 계정을 **삭제하고 다시 만들면** 그 작가의 형광펜·메모·북마크가 함께 사라집니다. 삭제는 마지막 수단입니다.
- **작가 권한 회수**: 작가·공유 창에서 **해제** 또는 공유 끄기. (계정 자체는 그대로)

## 7. 문제가 생겼을 때
| 증상 | 확인 |
|---|---|
| 로그인이 안 됨 | 이메일/비밀번호 확인 → 계정이 **Auto Confirm** 됐는지(Users 목록의 Confirmed) |
| 로그인 후 "이용 권한이 없습니다" | 그 계정에 뷰어 권한이 없음 → 1번 2단계(작가 추가) |
| "서버 설정이 필요합니다" | Supabase **Project Settings → API → Exposed schemas**에 `viewer` 추가 |
| "서버 연결 오류" | 인터넷 확인 → Supabase 프로젝트가 **일시정지**됐는지(무료 플랜은 오래 안 쓰면 정지, 대시보드에서 **Restore**) |
| 원고가 업로드 안 됨 | 오류 문구 확인. "파일이 너무 큽니다"면 회차를 나눠 올리기. 암호·배포용 HWP는 한글에서 일반 문서/HWPX로 다시 저장 |
| 북마크 저장 실패 | `supabase/migrations/002_bookmarks.sql` 실행 여부 확인 |
| 화면이 옛날 버전 | 앱을 완전히 닫았다 다시 열기(설치 앱), 또는 새로고침 |
| 하얀 화면 / "문제가 발생했어요" | 새로고침. 계속되면 화면의 **오류 내용**을 개발 담당에게 전달 |

## 8. 사용량 확인
Supabase **Project Settings → Usage**에서 DB·파일 저장 용량을 가끔 확인하세요(무료 플랜 한도는 대략 DB 500MB, 파일 1GB 수준). 한도에 가까우면 오래된 원고를 정리하거나 유료 전환을 검토합니다.
